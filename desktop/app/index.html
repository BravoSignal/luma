04 — CONNECTION
✓ ConnectedYouTube Music and Luma are paired.
▶

YouTube Music stays in your browser.

Windows & macOS · system media controls + browser extension

  1. Install Luma Bridge

    Get the companion extension from the Chrome Web Store, then open its options. It connects this desktop app to YouTube Music in your browser.

    For rating and playlist fixes, use Bridge 1.3.1 or newer. If the store version is older, use the local extension below.

    Local extension / developer setup

    Use this option for a newer bridge preview or an unpacked installation.

    Open chrome://extensions → enable Developer mode → choose Load unpacked. Select the folder containing manifest.json.

    On a Mac, press ⌘ + Shift + G in the picker and paste this folder path.

  2. Pair with Luma

    Open the Luma extension options, paste your pairing code and save it.

  3. Start your music

    Reload YouTube Music once. The extension adds shuffle, repeat and volume controls. Everything stays on your computer.
