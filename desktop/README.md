# Luma Desktop 1.7.6

[Downloads and features](../README.md) · [Setup](../docs/SETUP.md) · [Release process](UPDATE-RELEASING.md)

From this directory: npm ci, npm test, npm start. Mac builds require npm run native:mac; Windows builds require .NET 8 for native/windows/Luma.Media.csproj. Build installers with npm run dist:mac / npm run dist:win.

Bridge 1.6.3 is bundled. Store installs update independently after publication; unpacked installs require manual file replacement and Reload.
